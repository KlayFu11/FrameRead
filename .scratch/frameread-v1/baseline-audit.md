## 结论与版本

基线足以开始正式路线的 **S0 本地视频主链复现**；首个设计 Grill 的公共面仍属于**媒体接入与生命周期**。模块职责、持久事实、权限、复用边界及异步完成条件已定义。交付计划 1.0.0 于 2026-11-18 收敛，2026-11-19 以 1.0.1 迁入[唯一正式 S0～S12 文档](delivery-plan.md)，阶段和依赖保持不变。具体阶段使用以交付计划为准，通用规则见项目 AGENTS.md；本附件只提供源码差距和调查证据。异步派发待确认窗口仍有一项公共 Interface 决策，在 S6 的状态面冻结前澄清；其余发现主要是 Java 源码与目标契约之间的差距。

## 基线一致性与问题清单

针对 Q1～Q6，PRD R3-04～R3-10 与 SPEC §1、§4～§7 的主线一致。每个媒体固定首次采用的文本来源，重新导入产生新媒体。无有效字幕时进入 ASR，普通重发在无活动工作时可复用适用结果。旧材料可用时保留同媒体使用，缺失时保留阅读/导出并拦截依赖原材料的操作。跨媒体复用按同用户及实际输入验证，引用资源归目标媒体。202 以同代次的 broker 确认或消费者持久领取为据，结果与摘要分写，修订开始按有效作用域重置，与 ADR 0004 一致。ADR 0002 约束片外补充的使用范围，ADR 0003 约束未知用量和有限重试。PRD 明确当前视觉能力，真实帧与时码采用实际证据。基线保持同进程 Java 模块化单体及既有报告形式。[PRD R3-04～R3-10](../../docs/prototype/PRD.v3.md#r3-04-平台字幕自动选择) · [SPEC Q1～Q6](../../docs/prototype/SPEC.md#spec-scope) · [ADR 0002](../../docs/adr/0002-keep-background-knowledge-in-qa.md) · [ADR 0003](../../docs/adr/0003-retry-an-unconfirmed-model-call.md) · [ADR 0004](../../docs/adr/0004-bound-video-task-admission.md)
