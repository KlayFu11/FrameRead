# Triage labels

| 角色 | 本项目状态值 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已明确，可以交给 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 不予处理 |

Skill 提到上述角色时，使用表中对应的本项目状态值。
