# 只读分享绑定创建链接时的正式文章版本

部署者发出链接后，分享访问者应能再次读到同一篇文章，并看到支撑当时结论的配图。因此，每条分享链接固定指向创建时的正式文章版本；同一视频后来重试或生成新版，旧链接仍展示原来的正文、全片导图和引用图片。部署者撤销链接后，后续通过该链接发起的文章和图片读取请求均被拒绝，访问者此前保存的副本仍在其设备上。

依据见[已确认需求第 8～10 项](../research/FrameRead_Feasibility_Analysis.md#21-已确认需求清单)和[分享与撤销边界](../research/FrameRead_Feasibility_Analysis.md#64-分享导出与生命周期权限边界)。

## 补充决策：旧备份恢复后的分享失效（2026-11-15）

旧备份恢复不是普通容器重启。从旧备份恢复到新实例，或在原实例停机后替换为从备份恢复的新数据卷时，所有恢复出的分享记录默认不可访问：原有效记录标记为 `disabled`，已撤销记录保留撤销状态；旧分享 token 不自动重新生效。公开页面、文章内容和图片请求均在该状态下拒绝，不能由缓存、预签发资源地址或猜测资产 ID 绕过。

部署者核对恢复结果后，必须针对指定正式文章版本显式创建新的分享记录和新的 token。重新签发不复活旧 token，也不改变固定版本语义。普通 Docker 容器重启保持数据库中的分享状态：有效分享继续有效，已撤销分享继续拒绝。

该补充决策落实正式 PRD 的 REQ-09、REQ-15、AT-17、AT-23 与 S10；其余固定版本、最小公开数据面和撤销边界不变。
