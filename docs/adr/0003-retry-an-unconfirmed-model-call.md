# 外部模型调用结果未知时采用有界重试

## 决策

模型请求发出后，若无法确认供应商是否完成处理或产生多少用量，记录调用结果或用量为未知。消费重试、接管恢复与管理员重放执行各自的重试、期限和预算约束。

同一次受理的消费重试继承固定来源、预算配置及可确认的消耗。消费次数、耗时、模型调用、结构修复、用量和费用估算分别计量。永久消费失败或尝试耗尽进入失败记录流程，Agent 预算异常按 `BUDGET_EXHAUSTED` 结束。

管理员重放沿用同一协调入口，先校验失败记录、作用域、媒体和固定来源，再创建可追踪的重放代次。重放不抹除原调用未知状态，也不把未知结果改写为未发生。

本决策落实 [PRD.v3.md 的 R3-10](../prototype/PRD.v3.md#r3-10-进度失败与恢复) 和 [SPEC.md §7.3](../prototype/SPEC.md#spec-recovery) 的有限重试、预算与管理员重放合同。

## 影响

- 断连之后的额外调用受剩余预算和重试上限约束。未知的供应商用量在诊断中保持未知。
- 调用次数、耗时、已知用量、未知用量和费用估算必须可诊断。
- 失败重放可以复用已确认且仍匹配的阶段，但不能跳过作用域、来源和代次校验。
