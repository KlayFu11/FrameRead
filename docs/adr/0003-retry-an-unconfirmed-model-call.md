# 已发送的模型调用结果未知时，由部署者决定是否重发

当模型请求已发出、连接中断，且供应商既不能查询执行结果也不保证幂等重发时，自动重试可能造成第二次计费。本地任务在此处以失败结束，保留阶段成果与草稿，原调用的结果与用量记为未知。队列重投、Worker 重启、SDK 重试和文章编排恢复都必须遵守这个边界。

部署者可在原任务查看失败阶段和可能重复计费的提示，再主动发起关联原任务的重试。新尝试单独记录每次实际发送，原调用记录继续保留。本地任务失败不能证明供应商未执行或未计费。

验收时让可控模型服务记录收到请求的次数，在收到第一次请求后断连。重投消息并重启 Worker，核对服务仍只收到一次、任务已失败、用量未知、已有草稿可读。再主动重试一次，让服务正常返回，核对该步骤此时才收到第二次请求，两次调用均可追溯，原失败记录仍在。
