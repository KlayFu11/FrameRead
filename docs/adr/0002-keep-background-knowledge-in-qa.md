# 视频证据与片外补充分界

## 决策

结构化分析报告中的视频事实以实际取得的证据为依据，可定位的引用保留时间出处。报告中的分析判断、建议和创作内容按各自性质呈现。用户在后续追问中需要解释时可以获得片外知识，回答标明视频证据、推断与片外补充各自的依据。

片外补充不回写正式报告、报告的固定材料或结果 Checkpoint。没有可用的固定材料时，按材料缺失规则处理，不能编造时间出处或假定已经取得文字、音频或画面证据。

本决策适用于 [PRD.v3.md 的 R3-08](../prototype/PRD.v3.md#r3-08-结构化报告阅读与结果保存)、[R3-09](../prototype/PRD.v3.md#r3-09-连续追问反馈与计划修订) 和 [SPEC.md §5](../prototype/SPEC.md#spec-source)。

## 影响

- 报告、导出和阅读接口沿用正式报告及其视频证据边界。
- Agent、检索和追问链必须传递证据来源，不能用片外材料替代视频证据。
- 片外来源可服务于追问理解，但不改变报告完成、保存和恢复语义。
